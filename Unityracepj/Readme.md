체크포인트 1을 지나가면 체크포인트 1이 꺼지고 체크포인트 2가 켜지고
체크포인트 2를 지나가면 체크포인트 2가 꺼지고 체크포인트 3이 켜지고  
체크포인트 3을 지나가면 다시 시작점이 활성화되게 하려고 해 어떻게 코딩하면 될까
